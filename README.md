# Online Store Project

## Описание проекта
Этот проект представляет собой интернет-магазин, разрабатываемый в рамках учебного курса. 
Проект будет постепенно дополняться новым функционалом на протяжении всего курса.

## Технологии
- Python 3.x
- Django
- Bootstrap 5
- SQLite
